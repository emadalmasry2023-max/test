# منصة الاختبارات التفاعلية – المهارات الرقمية

مشروع عربي RTL جاهز للنشر على GitHub Pages، مع Google Sheets لحفظ نتائج الطلاب.

## الملفات
- `index.html`: واجهة الطالب والشرح والمراجعة والاختبار ولوحة المعلم.
- `Code.gs`: واجهة Google Apps Script لتسجيل النتائج وعرضها للمعلم.

## 1) تجهيز قاعدة بيانات النتائج
1. أنشئ جدول بيانات جديداً في Google Sheets.
2. افتح **الإضافات Extensions > Apps Script**.
3. احذف الكود الافتراضي والصق محتوى `Code.gs`.
4. احفظ المشروع.
5. شغّل الدالة `setup` من المحرر مرة واحدة ووافق على الصلاحيات.
6. لا تحتاج إلى إضافة خاصية كلمة المرور يدوياً؛ عند تشغيل `setup` سيتم ضبط كلمة مرور لوحة المعلم تلقائياً على كلمة المرور التي طلبتها.
7. اختر **Deploy > New deployment > Web app**.
8. اختر:
   - Execute as: **Me**
   - Who has access: **Anyone**
9. اضغط Deploy، ثم انسخ رابط Web app الذي ينتهي غالباً بـ `/exec`.

## 2) ربط الموقع بقاعدة البيانات
1. افتح `index.html` بمحرر نصوص.
2. ابحث عن السطر:
   `const CONFIG={API_URL:"",MAX_SCORE:20};`
3. ضع رابط Web app بين علامتي الاقتباس مكان القيمة الفارغة، مثال:
   `const CONFIG={API_URL:"https://script.google.com/macros/s/XXXXX/exec",MAX_SCORE:20};`
4. احفظ الملف.

## 3) النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub، مثلاً `digital-skills-exam`.
2. ارفع `index.html` إلى المجلد الرئيسي للمستودع.
3. من **Settings > Pages** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
5. انتظر ظهور رابط الموقع في صفحة Pages.

## 4) تجربة التشغيل
- افتح رابط الموقع، وأدخل اسم طالب تجريبي وفصله وبريده.
- جرّب الشرح والمراجعة ثم الاختبار.
- بعد التسليم افتح لوحة المعلم وأدخل كلمة المرور.
- تأكد من ظهور السجل في لوحة المعلم وفي Google Sheet.
- جرّب تصدير النتائج. سيُنزّل الموقع تقرير Excel بصيغة `.xls` المتوافقة مع Microsoft Excel، ويشمل بيانات الطلاب والدرجات وأوقات الاختبار وتفاصيل الإجابات الصحيحة والخاطئة.

## ملاحظات مهمة
- الأسئلة العشرة للاختيار من متعدد والخمسة للصح والخطأ مأخوذة من ملف الاختبار المرفق. تم اعتماد الإجابات المحددة في ورقة الصح والخطأ كما وردت في الملف.
- ورقة الاختبار الأصلية تذكر الدرجة الكلية 20 دون توزيع تفصيلي ظاهر؛ لذلك وُزعت الدرجات في هذه النسخة إلى 1.5 لكل سؤال اختيار من متعدد و1 لكل سؤال صح وخطأ.
- الشرح التعليمي صيغ لتفسير المفاهيم التي تظهر في الأسئلة، وليس نقلاً عن كتاب الطالب؛ أرفق الكتاب إذا رغبت بإضافة شرح المنهج كاملاً.
- لوحة المعلم تعرض النتائج داخل الموقع بعد تسجيل الدخول، ويمكن تحديثها من زر «تحديث النتائج».
- التصدير ينتج ملف Excel بصيغة SpreadsheetML بامتداد `.xls` المتوافق مع Excel، وليس صيغة `.xlsx` الحديثة.
- كلمة مرور المعلم تُضبط في Script Properties داخل Google Apps Script بواسطة `setup()`، ولا تُكتب في ملف `index.html` أو مستودع GitHub. عند تغييرها لاحقاً عدّل الثابت `TEACHER_DEFAULT_PASSWORD` في `Code.gs` ثم شغّل `setup()` وأعد نشر Web App إذا لزم.
- هذا نموذج مدرسي أولي. رابط Apps Script المنشور متاح لاستقبال إرسال النتائج، لذلك لا تستخدمه لتخزين معلومات حساسة. وللاستخدام الرسمي واسع النطاق، يوصى بإضافة آلية تحقق أقوى ومراجعة صلاحيات الوصول.
- بريد الطالب مطلوب في الواجهة كما طلبت، لكنه لا يُتحقق من ملكيته؛ هو حقل إدخال فقط.
